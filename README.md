# DeepTrust

DeepTrust is a deepfake detection platform combining audio, speech, image, and video analysis with a unified backend and GUI.

## Projects

| Folder | Description |
|--------|-------------|
| `DeepTrustBack/` | FastAPI backend for multimodal deepfake analysis |
| `DeepTrust-GUI/` | React frontend for the DeepTrust platform |
| `Deepfake-Audio/` | Audio deepfake detection models and scripts |
| `DeepFake-Speech-Detection/` | Speech deepfake detection (HM-Conformer) |
| `Deepfake-Image-Video/` | Image and video deepfake detection |
